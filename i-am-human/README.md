# i-am-human

Makes written output sound human and shorter, using the patterns catalogued in Wikipedia's [Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing).

Install from the skillforge marketplace (see the repo root README).

Triggers on writing tasks (emails, READMEs, posts, docs) and on requests like "make this sound human" or "less verbose". Invoke directly with `/i-am-human:i-am-human`.

- `skills/i-am-human/SKILL.md`: the writing recipe.
- `skills/i-am-human/patterns.md`: pattern catalog, loaded on demand.
