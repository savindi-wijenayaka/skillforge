# in-my-voice

Writes in Savindi Wijenayaka's blog voice: warm, chatty, analogy-led, with a Hola greeting and a Happy Coding sign-off. Built from her articles in `content/blog` on savindi-wijenayaka.github.io.

Use it with [`i-am-human`](../i-am-human). That skill keeps the content plain and free of AI patterns; this one sets the voice and format.

## Install

```
/plugin install in-my-voice --marketplace savindi-wijenayaka/skillforge
```

## Use

Triggers on requests like "write this in my voice" or blog and README drafting as Savindi. Invoke directly with `/in-my-voice:in-my-voice`.

## Files

- `skills/in-my-voice/SKILL.md`: the voice rules and a short example.
